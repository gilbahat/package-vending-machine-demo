# The allowlist: which package names this vending machine will serve.
#
# Versions are deliberately NOT pinned. The machine resolves whatever versions
# the upstream index currently offers, which is what lets an agent fetch a
# dependency closure it did not know about in advance. Safety of the resulting
# upstream URL is enforced by the F* validator, not by this file.
#
# This must be a TRANSITIVE CLOSURE. `pip install requests` needs urllib3,
# certifi, charset-normalizer and idna too; a closure that is merely "the
# things I asked for" fails on first use. See scripts/closure.sh for deriving
# one mechanically from a requirements file.
#
# Format: ecosystem:name   (ecosystem is 'pypi' or 'npm')

# ---- requests and its closure ----
